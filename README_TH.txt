SNOWTEE — เว็บไซต์แสดงเมนูสินค้า (Static Website)
=============================================

ไฟล์นี้เป็นเว็บเมนูเพื่อให้ลูกค้าดูผ่าน LINE Rich Menu รองรับมือถือ/คอมพิวเตอร์
- ค้นหาเมนู, แยกหมวดหมู่, เรียงราคา, ดูรายละเอียดสินค้า
- รูปสินค้าแยกจากภาพเมนูที่ร้านให้มา
- แสดงโปรโมชั่นเครื่องดื่ม+เบเกอรี่ ลด 5 บาท เฉพาะ อังคาร พุธ พฤหัส 14.00–16.00 น.
- แสดงข้อมูลบัตรสะสมแต้ม 50 บาท/แต้ม ครบ 10 แต้ม รับเครื่องดื่มฟรีตามกติกา
- ไม่เชื่อมระบบออเดอร์หรือฐานข้อมูลเดิม จึงไม่กระทบแอปกระทุ่มแบนไปด้วยกัน

คำเตือนก่อนเผยแพร่
1. ภาพเมนูต้นฉบับที่มีอยู่เป็นเมนูชุดก่อนหน้า โปรดตรวจทานราคาและชื่อสินค้าให้ตรงกับหน้าร้านปัจจุบัน
2. เมนูที่ยังไม่มีราคาที่ยืนยันจะแสดง "สอบถามราคา" ไม่ได้ใส่ราคาสมมติ
3. เว็บไซต์นี้เป็นเว็บแสดงเมนูเท่านั้น ไม่ใช่ระบบสั่งซื้อและไม่มีฟังก์ชันจ่ายเงิน
4. บางเมนูมีภาพขนาดเล็กจากภาพเมนูเดิม หากมีภาพสินค้าต้นฉบับความละเอียดสูง ให้นำมาแทนที่ใน assets/

เปิดดูบนคอม: ดับเบิลคลิก index.html

วิธีอัปโหลดบน GitHub Pages (แยกเป็น Repository ใหม่)
1. สร้าง repository ใหม่ เช่น "snowtee-menu" (ไม่ต้องแก้ repo แอปเดิม)
2. อัปโหลด index.html, style.css, main.js, menu-data.js, และโฟลเดอร์ assets/ ทั้งหมดลง root
3. Settings > Pages > Build and deployment > Deploy from a branch
4. เลือก branch main / root และบันทึก
5. รอสถานะ deploy เสร็จ แล้วคัดลอก URL https://USERNAME.github.io/snowtee-menu/
6. LINE OA Manager > Rich Menu > ปุ่ม “เมนูทั้งหมด” > ประเภท “ลิงก์” แล้ววาง URL เว็บเมนู

แก้ข้อมูลสินค้าในไฟล์ menu-data.js:
  name : ชื่อเมนู
  price: ราคาเป็นตัวเลข เช่น 40 (ไม่ต้องใส่ บาท)
  price: null ถ้าราคายังไม่ยืนยัน
  image: path รูปภาพ เช่น assets/milk-thai.webp
  category: หมวด fruit/milk/matcha/smoothie/ice/bakery/savory

การเปลี่ยนรูป: วางไฟล์ภาพใหม่ลง assets/ และเปลี่ยนชื่อ path ใน menu-data.js

สำหรับข้อมูลในเว็บไซต์: หากต้องการเพิ่มปุ่มสั่งซื้อโดยตรง จำเป็นต้องทราบลิงก์ร้าน SNOWTEE ในแอปกระทุ่มแบนไปด้วยกันที่ถูกต้องก่อน
