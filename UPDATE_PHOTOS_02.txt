SNOWTEE MENU — อัปเดตภาพสินค้าต้นฉบับ ชุดที่ 2

อัปเดตต่อจากเว็บไซต์ชุดที่ 1 (รวมรูป 7 ภาพก่อนหน้าอยู่แล้ว)
- เปลี่ยนภาพสินค้าเดิมเพิ่ม 24 รายการ และเพิ่ม 4 รายการที่พบในเมนู/สื่อสินค้าเดิม
- ชุดนี้มีไฟล์รูปต้นฉบับเพิ่ม 28 รูป (สำเนาเหมือนต้นฉบับทุกไบต์)
- คงราคาเดิมทั้งหมดสำหรับรายการที่มีอยู่แล้ว
- เมนูที่ยังไม่มีราคายืนยันยังคงแสดง 'สอบถามราคา'
- ปรับรูป Hero ให้ใช้ภาพที่ร้านส่งมาแทนภาพตัดจากแผ่นเมนู

อัปโหลด GitHub Desktop (Repository snowtee-menu)
1. แตกไฟล์ ZIP เฉพาะไฟล์อัปเดต
2. คัดลอกโฟลเดอร์ public จาก ZIP ไปวางทับโฟลเดอร์ public ใน Repository snowtee-menu
3. เลือก Replace เฉพาะชื่อไฟล์ที่ซ้ำ (อย่าลบไฟล์ที่ไม่ได้อยู่ใน ZIP)
4. GitHub Desktop > Commit to main > Push origin
5. Cloudflare Pages จะปรับเว็บอัตโนมัติหลัง Deploy Success
6. ลองเปิด https://snowtee-menu.pages.dev/ แล้วรีเฟรชหน้าใหม่ หรือเปิดโหมดส่วนตัว

หมายเหตุ: ภาพบางภาพเป็นสื่อโปสเตอร์ที่มีตัวอักษรในภาพต้นฉบับ เว็บจะแสดงทั้งภาพโดยไม่ตัดแต่ง
รายการเพิ่มใหม่: สมูทตี้มะม่วงนมมะพร้าว 39, ชาไทยคาราเมลบิสกิต 45, ชาไทยช็อกโก้ 40, ซันเดย์รสเกลือหิมะ 35
ยังควรตรวจสอบรายชื่อ/ราคา/ภาพจริงก่อนแชร์ลูกค้าทั่วไป

ไม่แตะ repository หรือโปรเจกต์ snowtee-stock และไม่ต้องแก้ Cloudflare setting
