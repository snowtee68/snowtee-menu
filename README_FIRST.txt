SNOWTEE ตลาดกระทุ่มแบน — อัปเดตภาพเมนูชาผลไม้โดยไม่ใช้ Python

ไฟล์ ZIP นี้ไม่ได้แทนที่เว็บไซต์ทั้งชุด และจะไม่ลบเมนูหมวดอื่น

วิธีใช้สำหรับ Windows 10/11 + GitHub Desktop:
1. เปิดโฟลเดอร์ GitHub repository ของเว็บ snowtee-menu ในเครื่อง
   ต้องเป็นโฟลเดอร์ที่มี public/index.html อยู่แล้ว
2. แตก ZIP แล้วคัดลอกไฟล์ทั้งหมดเข้าโฟลเดอร์ repository นั้น
   ถามให้รวม (Merge) โฟลเดอร์ public ก็ให้รวม แต่ห้ามลบของเดิม
3. ดับเบิลคลิก UPDATE_SNOWTEE_MENU.bat
   ใช้ Windows PowerShell ที่มีอยู่ใน Windows ไม่ต้องติดตั้ง Python
4. อ่านบรรทัด Image references corrected
   - ตั้งแต่ 1 ขึ้นไป: ระบบพบและแก้ลิงก์ภาพชาผลไม้ ให้เปิดตรวจเว็บก่อน Push
   - เป็น 0: ยังไม่สามารถยืนยันว่าภาพใหม่เชื่อมกับหน้าเว็บ อย่าเพิ่ง Push
             ให้ส่งไฟล์ public/index.html และ public/menu-data.js มาให้แก้ตรงจุด
5. เมื่อตรวจแล้วว่าแสดงถูก ให้เปิด GitHub Desktop > Commit to main > Push origin
6. Cloudflare Pages จะ deploy จาก GitHub หากโปรเจกต์ตั้งค่าเชื่อมอัตโนมัติไว้

เปลี่ยนเฉพาะ:
- ภาพเมนูชาผลไม้: public/assets/snowtee-fruit-tea-final.png
- ชื่อหมวด "ชาผลไม้สด" -> "ชาผลไม้"
- คำผิด "ซีรีส์ซาผลไม้" -> "ซีรีส์ชาผลไม้"
- ลบคำ "ผลไม้สดเต็มคำ"

ข้อจำกัด: ยังไม่ได้เห็น source ล่าสุดของเว็บจริง การแทนลิงก์ภาพจึงขึ้นกับ
โครงสร้างโค้ด หากรันแล้ว Image references corrected: 0 ต้องแก้จากซอร์สจริง
มีการสำรองเฉพาะไฟล์ที่แก้ไขไว้นอกโฟลเดอร์ repository เสมอ
